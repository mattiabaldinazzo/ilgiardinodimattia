# Il Giardino di Mattia

Sito vetrina per servizi di giardinaggio a Vicenza e provincia: potatura siepi, taglio erba, lavaggio con idropulitrice.

Sito statico (HTML, CSS, JS) pubblicato con GitHub Pages: https://mattiabaldinazzo.github.io/ilgiardinodimattia/

## Dati da personalizzare

Il numero `+39 000 000 0000` è un segnaposto. Sostituiscilo in:

- `index.html`: link `tel:`, `wa.me` e dati strutturati JSON-LD (`telephone`)
- `script.js`: campo `whatsapp` dell'oggetto `CONTACT` in cima al file

## Pubblicazione

Settings > Pages > Source: "Deploy from a branch", branch `main` (o quello di lavoro), cartella `/ (root)`.
