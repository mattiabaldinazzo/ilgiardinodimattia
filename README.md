# Il Giardino di Mattia

Sito vetrina per servizi di giardinaggio a Vicenza e provincia: taglio siepi, taglio erba, lavaggio con idropulitrice.

Sito statico (HTML, CSS, JS) pubblicato con GitHub Pages: https://mattiabaldinazzo.github.io/ilgiardinodimattia/

## Dati da personalizzare

Il numero `+39 000 000 0000` e l'email `info@ilgiardinodimattia.it` sono segnaposto. Sostituiscili in:

- `index.html`: link `tel:`, `wa.me`, `mailto:` e dati strutturati JSON-LD (`telephone`, `email`)
- `script.js`: oggetto `CONTACT` in cima al file

## Pubblicazione

Settings > Pages > Source: "Deploy from a branch", branch `main` (o quello di lavoro), cartella `/ (root)`.
